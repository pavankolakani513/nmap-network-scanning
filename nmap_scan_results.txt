4. OPEN PORTS AND SERVICES
--------------------------

Port 135 - MSRPC
Service: Microsoft RPC

Purpose:
MSRPC is used by Windows applications and services to communicate
with each other across a network.

Security Risk:
If unnecessarily exposed, RPC services can increase the attack
surface of a Windows system. They should be protected by appropriate
firewall rules.


Port 139 - NetBIOS-SSN
Service: Microsoft NetBIOS Session Service

Purpose:
Used by Windows systems for network communication and legacy
file/printer sharing.

Security Risk:
If exposed unnecessarily, it can reveal network information and
increase the attack surface.


Port 445 - Microsoft-DS / SMB
Service: Microsoft SMB

Purpose:
SMB is used by Windows for file and printer sharing and other
network services.

Security Risk:
SMB should be properly secured because vulnerable or improperly
configured SMB services can create security risks.
